Ticketing System --- PostgreSQL CRUD Operations,

Project Overview

This project is the beginner stage of a Ticketing System.
The current stage focuses on learning and implementing CRUD operations using PostgreSQL.

CRUD stands for:

Create --- Create database tables and insert records
Read --- Retrieve and view records
Update --- Modify existing records
Delete --- Remove records

PostgreSQL CRUD Operations and basic operations:

The project contains:

1. Create the Table - Creating an employee's table
                      Defining primary keys and unique constraints
                      Applying NOT NULL constraints
2. Read Data - Read the table.
3. Create / Insert Employee -Inserting employees
4. Update Employee - Updating employee information
5. Delete Employee - Deleting employee records
6. Basic SQL Operations - Filtering employee records
                          Limiting query results
                          Selecting specific columns
                          Filtering the specific column
                          Searching names using LIKE
